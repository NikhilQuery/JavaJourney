# 📁 Arrays and Methods

This folder documents dynamic storage manipulation and structural code reusability using static and instance subroutines.

## 📝 Learning Log & Files

### 📊 Chapter 6: Arrays in Java
* **`MatrixAddition.java`**: 2D Array Practice - Performs element-wise addition of two-dimensional matrices using nested loops.
* **`ArrayReverse.java`**: Array Manipulation - Inverts elements in-place using an efficient two-pointer swapping algorithm.

### 🛠️ Chapter 7: Methods in Java
* **`SmartCalculator.java`**: Modular Logic - Isolates individual arithmetic behaviors into separate instance methods.
* **`UltimateCalculator.java`**: Advanced Logic Consolidation - Combines method overloading, variable arguments (VarArgs), recursion, and static memory allocations inside a single menu-driven platform.
* **`Method_practice_Set.java`**: Method Practice Set - Solves core problems covering multiplication tables, nested-loop star patterns, and recursive Fibonacci/summation logic.
